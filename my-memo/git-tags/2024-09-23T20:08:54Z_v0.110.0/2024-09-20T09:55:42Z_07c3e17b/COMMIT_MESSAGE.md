    #### Description
    
    Adds support policy for Collector SIG software artifacts with the
    following principles:
    - Support means that we will, at a minimum, fix critical bugs and
    security issues. We MAY fix other bugs and/or add features if needed
    (e.g. because a feature eases transition to a v2), but this is not
    required
    - We support artifacts for end-users for longer
    - Artifacts may contain sub-components that are not stable. The
    important bit is that users can easily tell when something is unstable.
