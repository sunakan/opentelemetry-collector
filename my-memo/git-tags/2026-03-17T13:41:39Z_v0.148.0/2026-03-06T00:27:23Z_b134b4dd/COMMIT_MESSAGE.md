    #### Description
    
    This PR extends `mdatagen` with ability to generate schema for component
    config parts that are generated by mdatagen, e.g.
    `MetricsBuilderConfig`.
    
    This step is needed in the process of building full component config
    schema and is part of the plan established in [component configuration
    schema roadmap
    RFC](https://github.com/open-telemetry/opentelemetry-collector/blob/main/docs/rfcs/component-configuration-schema-roadmap.md).
