    #### Description
    
    Adds [AGENTS.md](https://agents.md/) file. The intent of this file is
    to:
    1. Make sure there is a human in the loop when creating a PR or posting
    issue comments.
    2. Make sure that commits created primarily by an agent are easily
    identifiable by reviewers
    
    This is heavily inspired on the [Open Policy Agent AGENTS.md
    file](https://github.com/open-policy-agent/opa/blob/main/AGENTS.md) and
    the [Fedora AI-assisted contributions
    policy](https://docs.fedoraproject.org/en-US/council/policy/ai-contribution-policy/).
    
    This only affects agents that are compliant with the AGENTS.md file (see
    https://agents.md for list of tools that support it), as well as Claude
    Code using [this
    workaround](https://code.claude.com/docs/en/claude-code-on-the-web#best-practices).
