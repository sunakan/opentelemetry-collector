    This PR enables contributors to re-trigger failed jobs by using the
    /rerun comment in the PRs.
    
    The same was done in the [contrib
    side](https://github.com/open-telemetry/opentelemetry-collector-contrib/pull/44957),
    and I think it is valuable to port it to the core side.
